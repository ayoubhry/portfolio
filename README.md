## ✨ Fonctionnalités

- 🎨 Design **dark** professionnel (navy + cyan)
- 🌐 Animation **canvas** particules dans le Hero
- ⌨️ Effet **typewriter** sur le sous-titre Hero
- 📜 Navbar **sticky** avec lien actif au scroll
- 🎞️ Animations au **scroll** (Intersection Observer)
- 📱 **Responsive** (mobile, tablette, desktop)
- ♿ Support `prefers-reduced-motion`

## 📦 Déploiement

```bash
# 1. Cloner le repo
git clone https://github.com/ayoubhry/portfolio.git
cd portfolio

# 2. Ajouter vos fichiers
cp votre-photo.jpg assets/img/photo.jpg
cp votre-cv.pdf assets/cv/CV_Houraoui.pdf

# 3. Push sur GitHub
git add .
git commit -m "feat: initial portfolio"
git push origin main

# 4. Activer GitHub Pages
# Settings → Pages → Branch: main → / (root) → Save
```
